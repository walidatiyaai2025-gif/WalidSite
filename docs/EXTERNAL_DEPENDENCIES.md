# Pre-known external inputs not contained in this file (not invented)
- Current domain and hosting logins/SSH or deployment token; access control must be established.
- TLS certificates, email delivery credentials, SMS/push sender if applicable.
- At least one working AI provider endpoint + confidential key/access; local provider network allowlist.
- Developer store accounts, package ID approvals, signing keys/certificates and privacy declarations.
- Approval to publicly describe any confidential government project or employer system (default: anonymise).
- Canonical product name in store and legal privacy policy legal basis/retention jurisdiction.
These should not block independent UI/application development; they block only their corresponding live integration or public release.
