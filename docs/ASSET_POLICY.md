# Asset governance
- `/assets/portraits/portrait-original-user.jpg` is the sole canonical owner headshot. Its modified light version only changes background/format; preserve source.
- Never infer identity, create alternate faces, or treat generated illustrations as real owner images.
- 40 `/assets/screen-reference/*.png` are synthetic design mockups; screenshots are **not evidence of implemented features**. Some metrics/labels inside are illustrative and forbidden as actual claims.
- Blog fallback covers are local generated graphics; runtime article imagery is AI-generated through admin configured image model, traced by model/date/prompt/rights.
- SVG icons and logo are source files; app icon PNGs should be regenerated from vector for production; check optical consistency at multiple sizes.
- Preserve alt text and LTR/RTL layout; no unlicensed commercial font files bundled.
