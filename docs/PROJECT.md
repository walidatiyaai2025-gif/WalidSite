# Product canonical scope
- Site: professional identity, recruiter view, case studies with evidence, public GitHub, searchable blog, technical tools.
- Flutter: developer companion with AI troubleshoot, offline runbooks, saved guides, learning/interview aids.
- Admin: AI providers selfhosted/paid, routing/costs, image studio, content automation, GitHub allowlist, evidence, approvals, analytics.
- Fully autonomous ordinary development and low-risk content; external infrastructure/security/permissions cannot be forged.
- Web public pages must be SEO-indexable; app is a productivity tool, not a WebView wrapper.
