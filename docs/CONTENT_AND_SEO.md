# Publishing verification
Flow: topic -> official sources -> draft -> code/safety verification -> visual generation -> citations/license gate -> duplicate/cannibalization check -> publish -> recheck on version changes.
Every article has author attribution, created/updated date, technical versions, tested/unverified label, full citations and canonical URL. No fake first-hand test claims.
Use stable redirects from older site, sitemap, robots, localization alternates and OpenGraph assets. No AI content spam.
