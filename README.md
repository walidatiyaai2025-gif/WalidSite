# WALEED ATIYA – COMPLETE DEVELOPMENT INPUT PACK v6.0

This is a source-of-truth **design/asset/implementation-contract pack**, not a running site or compiled app. It contains 40 UI reference images, the unchanged owner photo, derived crops, production-oriented vector logos, SVG icons, Flutter/PWA/app icons, 8 fallback article covers, 3 social share images, 6 state illustrations, tokens, 40 screen specifications, API and database blueprints, AI provider contracts, worker task graph, governance templates and two CI templates.

## Entry points
- `docs/PROJECT.md` — product scope
- `worker-contracts/AGENTS.md` — no-duplication contract
- `tasks/master-task-register.json` — plan, NOT actual created GitHub issues
- `contracts/screens.json` — one source for 40 routes/screens/actions
- `design/tokens.json` — one source for UI tokens
- `api/openapi-contract.yaml` — proposed routes, responses require schema refinement and tests
- `database/schema-blueprint.json` — migration contract, not deployed DB
- `docs/EXTERNAL_DEPENDENCIES.md` — real blockers not to fake
- `MANIFEST.json` — file hashes after packaging

## Mandatory distinction
Design images may contain illustrative placeholder metrics and UI. Do not publish their numerical values as real and do not treat them as screenshots of working software. The presence of a file does not prove its implementation was compiled or tested.

## Safe asset sources
- Real photo: supplied by owner; derivative light portrait created without prompt-based face synthesis.
- SVG icons/logo and fallback images: created as local implementation assets (vector/generated geometry).
- No secrets, credentials, customer data, old SQL dump or font binaries included.
